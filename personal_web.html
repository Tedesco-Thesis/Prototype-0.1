what this prototype is testing
QUESTION: when a digital identity is built from standardized fields and behavioral data, what disappears when a person is allowed to represent themselves on their own terms?
INTERVENTION: the same person is described three ways — self-authored, standardized-form, and machine-inferred — using the same underlying content.
TRADEOFF: the standardized profile is faster to scan and compare across people; the self-authored place is slower to make and slower to read, but resists being reduced to a category.
OBSERVATION: watch which version a visitor trusts more, and whether the machine-inferred profile feels accurate, flattering, or slightly wrong in a way that's hard to correct.
LIMITATION: the "machine profile" here uses simple, transparent rules — a real inference system would be far less legible than this, which may make this version feel more benign than it should.
